API Key 儲存位置項目根目錄 .env 或服務環境變數

首次使用：將項目根目錄的 .env.example 複製為 .env，填入以下三項並儲存。之後雙擊 poc/run_web.bat 即可啟動，無需每次重新輸入。

COMPANY_API_BASE_URL
COMPANY_API_KEY
COMPANY_CHAT_MODEL

修改 .env 後請重新啟動服務。既有環境變數會優先於 .env。Key 只由本機服務讀取，不回傳或儲存於瀏覽器；請保留本機 .env，不要上傳至 GitHub。

支援完整文件路徑或資料夾路徑。儲存後立即重新讀取，無需重新啟動。

其他連線說明

僅排查問題時開啟，發送一次後自動關閉。原文可能包含業務資料，會保存在本機結果目錄；一般回答和引用仍正常保存。

框架資料：將獲准使用的 Markdown 文件複製至項目的 .poc-data/framework/reference.md，再於 .env 加入以下設定。框架文件與 .env 均不會隨 GitHub 下載，換電腦時需要另外複製。

FRAMEWORK_REFERENCE_PATH=.poc-data/framework/reference.md

填好設定後，點選「測試模型連線」，確認模型能返回文字。
