# 业务回答修复探针

这 5 题检查调用阶段、参数回写、校验优先级，以及外部请求前后字段值的区别。题目最初由独立代理依据公开合成源码编写，随后用于本轮开发和复测；不作为留出测试集。

`manifest.json` 记录源码根目录与题目文件。每题保留源码范围、内容哈希、应有结论和禁止断言。评分同时检查主问题及附加正文，不能用正确的主结论抵消后文错误。失败尝试与修复后复测分开保存，不改写题目标准来适配答案。

执行时使用现有 `poc/live_business_eval.py`，按 manifest 中的 source/cases 运行；公开样例验证显式传入 `--framework ''`，避免混入本机私有资料。模型配置从本机 profile 读取，不提交密钥、地址或配置。代理源码审读与 COBOL 运行验收分别记录。
