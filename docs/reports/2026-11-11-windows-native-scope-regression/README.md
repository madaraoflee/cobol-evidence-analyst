## 源码因果对照和最小提案

生产问答入口在三个互相调用的中性程序和四份 COPY 上复现相同的义务数量与三次请求。只限制已读路径进入定向公式义务，实际恢复到两条公式、两条条件、三处声明、两个未知运行输入，以及一次模拟请求。原定向源码的依赖证据继续可用。详见 [实测对照](causal-source-reproduction.json) 和 [Windows 前后对照](native-before-vs-earlier-passing.json)。

[最小提案](PROPOSED-SCOPE-FIX.diff) 仅在本地问题明确限定文件或段落时，把已读导航与公式义务分开，并重新计算旧的定向规则游标。先前正文、源证据、普通公式分批以及全库调查保存继续沿用。把普通公式的跨路径游标一并关掉会重新造成 BUG-20261106-026，故保留它。该提案待本地核心冻结例外授权后应用；真实 Windows 60 秒门槛及最终同包验收仍需重跑。
