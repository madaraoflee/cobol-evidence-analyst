# BUG-20261111-026 Windows 回归分组累计超时

Windows run 42971680136 中，10,001 文件在线用例在 1,410.820 秒实际通过，本地用例在 227.220 秒通过。该组随后碰到原 45 分钟时限。最后一个已开始的旧回读用例执行了 1.885 秒即被中断，另有 338 项未开始。17 项新产品回归都在其它组实际通过。此运行仍是失败，未生成候选。

旧分组按用例数量平衡，没有给耗时占半组以上的万文件模块预留容量。现给原有四组中的第一组安排整个万文件模块，另外三组按原算法分摊其余用例。核对实际发现的 5,419 个测试 ID，分组为 7/1804/1804/1804，覆盖完全一致，每项一次。每组 45 分钟、运行顺序、源代码断言与聚合门禁继续沿用。

三个新增维护回归核对严格分组、参数校验与工作流合同。历史耗时投影只用于选择分组方式，下一轮真实 Windows 结果单独核验。
