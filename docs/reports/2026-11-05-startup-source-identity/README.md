## 已修复的路径

`请解释source-dir/root.cbl中的计算规则` 原先把请求动词或“中的计算规则”并入文件身份，生成不存在的路径，严格来源约束随后拒绝供应任何源码。现在先尊重实际索引中的完整文件名，再移除明确的中文请求语法；保留目录、Unicode 名称、大小写匹配、同名歧义和真实缺失限制。新增反例在修复前出现八处断言失败，修复后普通问答首请求实际携带对应公式。该缺陷历史早于最近候选，不能单凭此复现断定最近版本才引入问题。

旧解析器索引在打开窗口前执行 SQLite 全库完整性检查，现在在可取消的升级任务中执行。任务重新核对同一升级身份，通过后才能备份和重建；取消、库已改变或检查失败均不能进入写入步骤。旧解析器升级仍可能需要重建索引；本次没有跳过必要的源码解析或完整性检查。

10 月 29 日的解析器版本更新会让旧库首次打开时进行一次完整迁移。成功后重新打开会复用新索引；失败和中断会留下记录，避免反复自动重建。本次没有再次升级解析器或搜索索引版本。大型报告恢复仍须校验完整内容；旧库升级期间同一大型诊断报告在界面出现前可能校验三次，缺少可用显示副本的旧报告还需首次完整解析。没有现场日志和报告大小，无法确认这些耗时在该设备上的占比。
