## 已修复的路径

旧解析器索引在打开窗口前执行 SQLite 全库完整性检查，现在在可取消的升级任务中执行。任务重新核对同一升级身份，通过后才能备份和重建；取消、库已改变或检查失败均不能进入写入步骤。旧解析器升级仍可能需要重建索引；本次没有跳过必要的源码解析或完整性检查。
