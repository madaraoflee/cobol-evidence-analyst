# 完整问答链路的重复工作与等价修复

这次测量针对已导入资料库上的完整问题，不将冷导入提速当作问答提速。上一候选 Windows 报告中，主问答暖样本中位数为 11.72 秒，业务分析内部记录约 7.69 秒；差额发生在内部计时结束之后，不能全部归因于模型或源码推导。

## 已定位的耗时

工作台在问题完成后为了显示最多 200 条关系，每次重新查询整个资料库的 CALL/COPY 图。对固定的 12,024 个文件、2,712,992 行源码，完整工作台测量复现了每题约 2.4～5.3 秒的关系查询。单独重复运行 SQL 能因磁盘缓存降到约 0.16 秒，但不代表经过完整业务分析后的真实成本。历史追加仅约 0.02 秒，因此本次没有改历史存储来提速。

请求准备还会在每次预算适配时重复投影相同的导航事实，并对全部候选路径重复扫描调用关系。这些是本地重复计算，不是新增业务分析。

仅处理界面预览后的第一次对比仍出现 17.12 秒慢样本；其中 11.55 秒集中在业务地图构建。进一步剖析确认，广域问题的程序定义查询按每 400 个文件执行一次，路径索引让它访问了各文件的所有代码单元正文页，再筛选 Program。这 31 批查询是主要的磁盘敏感点；既有导航图缓存实际命中，没有发生重复图加载。该中间结果完整保留，未当作最终修复结论。

## 修改范围

工作台只在同一数据库的文件身份、大小、纳秒时间和 SQLite 文件头均未变化时，复用一份已有的界面关系预览。每次复用仍在短暂只读事务中核对快照；存在未清空的 WAL/回滚日志、文件变化或无法可靠识别时使用原查询。原查询的 SQL、排序、200 条显示范围均未修改。缓存仅留一份深复制结果，不保留数据库连接，不会锁住 Windows 导入时的文件替换。

另外实际复现并修复了 Windows 时间戳边界：WAL 更新后完成 checkpoint、还原 mtime，而创建时间和数据库头不变时，旧的文件签名可能误认为没有更新。Windows 现在从已经打开的文件句柄读取系统 [FILE_BASIC_INFO.ChangeTime](https://learn.microsoft.com/en-us/windows/win32/api/winbase/ns-winbase-file_basic_info)，不把创建时间当修改时间；元数据不可用时只关闭缓存复用，继续原查询，不阻止回答。

投影只在本次函数调用的不可变阶段复用编码和保护字段遍历结果；发生记录替换后重建局部缓存。调用路径筛选改为一次建立集合，再按原路径顺序输出。完整源码页、业务事实、引用编号、压缩阈值、模型请求限额和答案检查保持不变。解析器和问答协议版本不变，避免为等价的性能调整强制重导入或使历史调查失效。

广域程序定义查询现在一次扫描原有的 program/type 索引，先排除非 Program 单元，再读取真正需要的定义；小范围仍沿用路径查询。选择条件是超过 400 个文件且至少覆盖半个资料库，旧快照缺少该索引时退回原查询。无需添加数据库索引或更改导入。完整对照包含重复与嵌套定义、没有 Program symbol 的定义和来源版本；有序输出必须相同。

## 测量方法与内容对照

`tools/benchmark_question_latency.py` 用同一台 Mac、同一 Python、同一份冻结源码和原始索引的只读备份，串行运行旧版 `b636fbd` 与修复版。两边经过真实 `WorkbenchState.start → _run → _record_answer → get_job`，计入后台工作、结果复制与 JSON 编码；不包含 HTTP 传输和真实模型生成。使用桌面默认 8192 输出 token、60 秒连接超时及固定案例策略，所有 socket 连接被阻止，回答由内存中的合成接口返回。每边四次，首个样本与后三个暖样本分开记录。cProfile 单独运行，不计入速度统计。

早期定位报告曾使用 1024/20 配置，保留原记录并标明差异；最终速度对比只使用修正后的同配置报告。完整样本、异常慢样本均保留，不删除不利结果。

实际供证按路径、版本、行范围、完整正文和截断状态计算摘要；同时比对完整请求、最终答案与 claim ledger。重建工作台后再次检查保存的对话可恢复。精确结果见同目录 `verification.json`。

最终 Windows 包另在同一个构建任务中与两个固定旧包串行运行相同大库案例，报告分别列出主问答和附加范围问题，避免把两题合计当作一题。所有模型响应均为本地合成；离线内容等价不代表真实模型准确率评分。

## 重现

```sh
python3 tools/benchmark_question_latency.py \
  --source-tree /path/to/immutable-code \
  --source /path/to/frozen-large-source \
  --index-from /path/to/original-large-index \
  --output /path/to/new-measurement \
  --files 12000 --lines 224 --longest 25000 \
  --repeats 4 --surface workbench
```

测量时不要并行运行其他测试或修改生产代码。Windows 手动构建使用 `compare_previous_candidates=true`，不需要真实模型凭证。正式发布的同包联合验收要求保持原样；缺少真实模型、人工或目标办公设备验收时，仅交付公开候选版本。
