# 调查模式与源码记忆独立于整题预算

旧实现以请求次数是否有限来选择调查模式，导致增加额度保护时关闭跨轮源码记忆；旧恢复流程又重新计时，持续流式活动可能维持无期限的等待。标准问答改为共享 180 秒硬期限与 6 次全部模型请求，保留最多 5 个调查轮、2 次无新证据的定向修订和默认 45 秒收尾预留，调查模式及记忆各自配置，以保证大源码调查有上下文且及时交付。

旧的空额度迁移到有限默认，已有更严格请求和时间额度不扩大；旧 `max_answer_revisions` 的 `0/1` 格式保留并映射到更严格的计数额度。恢复同时保留已耗时间、绝对期限和请求账本，断线不会补回预算。接口的无活动超时仍独立工作，但不能延长整题期限；深度调查须显式配置且最多 300 秒。

这取代 ADR-0013 的默认无限等待选择。达到边界时停止新调查，保留已经核实的内容及具体未完成项；硬期限控制的是本地等待和调度，不声称远端一定停止计费。离线测试只证明预算、取消和恢复机制，真实模型的正确性与速度仍需同题对照；本轮不构建或发布桌面包。
