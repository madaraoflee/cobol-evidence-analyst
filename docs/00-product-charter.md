# 产品章程：源码证据型 COBOL 业务分析 Agent

> 核心判断：第一版只解决一个高价值问题——业务分析人员提出一个具体业务问题，系统能够自行定位相关 COBOL 逻辑、追踪调用与数据来源，并给出带源码证据和不确定项的业务回答。

## 1. 要解决的问题

大型 COBOL 系统的业务规则分散在主程序、Paragraph、`PERFORM`、子程序、COPYBOOK、SQL、文件和控制表中。分析人员必须依赖经验手工追踪；速度慢、覆盖不稳定，而且已有文档常常无法证明仍与当前代码一致。

普通向量 RAG 只能找到“看起来相关”的代码，不能可靠证明字段如何流转、哪个条件控制结果、跨程序参数如何传递。因此本产品的价值不在于总结更多代码，而在于缩短一次可信代码调查的时间，同时保持可复核性。

## 2. 第一目标用户

首要用户是负责香港保险遗留系统、需要解释现有行为的业务分析师和系统分析师。架构师、开发人员和测试人员是第二批用户；自动修改代码、自动发布和完整 SDLC 编排不属于第一版。

## 3. 第一版产品楔子

第一版限定在一个香港保险业务域、30–50 个相互关联的程序和首批 20–30 个金标准问题，优先回答五类问题：

1. 某字段或金额在哪里计算，公式是什么？
2. 每个字段在哪里定义，以及它在目标路径上的值来自哪个参数、程序、SQL、文件或控制表？
3. 哪些条件、客户类型、状态或异常分支会改变结果？
4. 哪条 `PERFORM / CALL / GO TO` 路径会执行到这段逻辑？
5. 现有源码不能确认什么，为什么不能确认？

## 4. 用户得到的结果

每次回答必须同时给出：业务语言解释、关键公式或规则、执行路径、数据来源、源码证据、分析快照和待确认项。系统必须明确区分代码事实、业务推断和待确认项。

## 5. 成功标准

以下是 M1 阶段需要用真实样本校准的首版门槛，而不是已经达成的承诺：

| 维度 | 退出门槛 |
| --- | --- |
| 证据完整性 | 每条代码事实都有至少一个可复核 `evidence_id`，目标 100% |
| 虚构控制 | 不存在源码中未出现的程序名、字段名、Paragraph 或位置，目标 0 次 |
| 结构识别 | Program、Section、Paragraph 识别率目标 ≥ 98% |
| 调用关系 | `PERFORM/CALL` 精确率目标 ≥ 95%，召回率目标 ≥ 90% |
| 证据检索 | 至少 85% 的金标准问题在 Top-5 证据中包含正确路径 |
| 回答可用性 | 至少 80% 的回答被业务分析人员评为可直接用于调查或复核 |
| 拒答能力 | 对已知不可由源码回答的问题，不把推断写成代码事实 |

## 6. 明确不做

- 不把整个代码库直接塞给大模型。
- 不把向量相似度当作事实证明。
- 不通过微调让模型“记住”公司源码。
- 不在 MVP 中自动修改、提交或发布代码。
- 不在证据层尚未通过验证时扩展到 UR、FS、TS 自动生成。
- 不把 CodeGraph、ProLeap、LangGraph、Neo4j 或任何模型预设为不可替换的核心。

## 7. 产品原则

**证据先于解释**：解析器和图查询提供事实，大模型负责理解问题和翻译业务含义。

**垂直而非通用**：优先解决 COBOL、企业方言和表驱动业务规则，而不是与通用代码助手竞争。

**渐进式自主**：从只读建议和人工复核开始；只有质量门槛稳定后，才增加影响分析和 SDLC 产物。

**评估先于规模**：先建立金标准问题和错误分类，再调模型、检索或图算法。

**数据构成护城河**：长期价值来自企业方言规则、经过确认的业务概念、金标准问题和反馈闭环，而不是绑定某一个基础模型。

## 8. 关键假设

- 源代码、COPYBOOK、SQL 和调用相关文件可以在批准的内网环境中读取。
- 至少有一名业务专家可以确认金标准答案和术语。
- 第一阶段允许选择一个有代表性的业务域，而不是一开始覆盖全公司代码。
- 系统可以保留源码版本标识、文件哈希和分析审计记录。

若这些假设不成立，项目应先解决数据与治理条件，而不是继续堆叠 Agent 能力。

## 9. 私密语料边界

公司源码、内部文档和付费 DXC 文档不进入公开项目、个人开发环境或未经批准的外部模型。公开开发只使用公开 IBM 资料与原创合成保险样本；DXC 规则、公司术语、真实索引和金标准答案只在公司批准的环境中构建和运行。所有大模型调用只允许使用公司提供的 API Key 和公司 API；工作电脑不安装本地模型运行时。

因此产品必须同时支持两套验证：公开侧验证通用 COBOL 能力，公司侧验证真实方言和业务有效性。公司侧可以回传聚合指标、错误类别和获准公开的最小复现样本，但不能用源码摘录作为远程调试材料。
