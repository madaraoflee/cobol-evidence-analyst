# 业务分析 POC：服务申请业务链

当前演示能力、真实接口状态和源码新鲜度限制见[当前实现与已知限制](../16-current-implementation-status.md)。合成案例和有效引用不能替代公司真实业务验收。

领导汇报使用 [POC 演示说明 Word 文档](./COBOL业务分析系统POC演示说明.docx)，包含业务目标、三类案例规则、现场演示流程及验收依据。

当前演示统一从本机工作台进入：`python poc/web_app.py`，Windows 双击 `poc\run_web.bat`。通过 GitHub 更新代码，保留本机 `.env`；公司接口地址、模型和密钥仍只配置一次。

默认围绕服务申请受理、在线复核、夜间生效组织，解释办理条件、业务规则、申请状态变化和异常影响。传统联机、控制器分段联机和批处理作为还原业务的技术依据。红白商务界面、简体中文／繁體中文／English、真实源码引用、进度、导出与 API 原始返回继续保留。

先选择业务场景看合成案例导读，再点击“载入此案例”进行实际索引。配置公司接口后点击“开始业务分析”，才能得到本次模型回答。导读不会冒充模型结论；加载案例也不自动联网。换问题或改源码后需要重新分析。

旧保费静态原型、独立演示页面和截图已经移除，不再提供旧入口。历史技术报告仅用于追溯研发过程。

完整操作与框架对应见[系统使用手册](../15-system-user-manual.md)。
